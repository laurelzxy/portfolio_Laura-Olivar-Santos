AR SHOP

Projeto acadêmico · Unity · Realidade aumentada · Mobile

Sobre o projeto

O AR SHOP é um aplicativo desenvolvido para auxiliar empresas na venda remota de produtos, como televisores, teclados e monitores. Utilizando a câmera do celular, o comprador pode posicionar virtualmente os itens no ambiente desejado e visualizar como eles ficariam em sua casa.

A experiência permite avaliar se o produto combina com as cores, o estilo e o espaço disponível, tornando a escolha mais imersiva e personalizada. O aplicativo oferece uma variedade de produtos para testes virtuais, de forma prática e acessível, diretamente pelo celular.

Atuação

  • Seleção e ajuste de assets 3D, considerando proporções realistas
  • Participação no Game Design e na definição da experiência do usuário
  • Planejamento das interações em realidade aumentada

Tecnologias

  • Unity
  • Realidade aumentada
  • Modelos 3D
  • Mobile

Take It Back

Game Dojo · Desenvolvimento de jogos · Game Design · UI/UX

Sobre o projeto

Take It Back foi desenvolvido durante um Game Dojo, desafio intensivo de uma semana dedicado à criação de soluções para jogos digitais. Nossa equipe atuou como uma força-tarefa da PixelForge Studio, com a proposta de criar um sistema gamificado para organizar e gerenciar os materiais consumíveis utilizados na produção de jogos.

O desafio foi transformar um processo corporativo em uma experiência interativa. No jogo, o participante assume o papel de um colaborador responsável por analisar e aprovar os itens entregues pela equipe. Para isso, consulta fichas com identificação, nome e informações dos materiais em um tablet interativo.

Atuação

Fui responsável pelo Game Design e pela criação das interfaces UI/UX, trabalhando para que as interações fossem claras, funcionais e alinhadas à proposta do projeto.

A solução utiliza conceitos de gamificação para incentivar a organização, o uso consciente de recursos e a responsabilidade coletiva, demonstrando como mecânicas de jogos podem apoiar processos internos de uma empresa.

Competências aplicadas

  • Game Design
  • UI/UX
  • Gamificação
  • Design de interfaces

Harvest Game

Projeto autoral para portfólio · Game Development · C# · Pixel art

Sobre o projeto

Harvest Game é um projeto autoral desenvolvido para compor meu portfólio. O jogo segue o estilo catch game, no qual o jogador precisa coletar itens que aparecem e caem pela tela, reagindo rapidamente e tomando decisões para manter seu progresso.

Durante a partida, diferentes tipos de itens surgem e apresentam recompensas ou penalidades. Essa variação cria um desafio progressivo, exigindo atenção e adaptação conforme o ritmo do jogo aumenta.

Minha atuação

Fui responsável pela programação e pela criação dos assets visuais em pixel art, trabalhando no desenvolvimento das mecânicas e na identidade visual do jogo.

O projeto está em desenvolvimento e passa por ajustes na interface, implementação de músicas e efeitos sonoros e polimento geral da experiência.

Tecnologias e competências

  • Game Development
  • C#
  • Pixel art
  • Programmação
